# COMET 시작하기

COMET은 촉매의 조성, 담체, 제조 단계와 가격 자료를 바탕으로 제조 원가를
추정하는 도구입니다. Windows 앱이나 웹 화면에서 같은 계산 기능을 사용합니다.
실험 결과나 공급사 견적을 대신하는 값이 아니라, 연구 초기의 조성·제조법
비교에 쓰는 추정치입니다.

화면 왼쪽의 **언어**에서 한국어를, **표시 단위**에서 kg 또는 lb를 선택합니다.
금속 기호와 단위는 그대로 표시합니다. 문헌 요약, 계산 모델의 경고문,
출처 메모 등 자료에 포함된 문장은 원문을 유지합니다.

## 열촉매 원가 계산

1. **원가 계산**에서 **열촉매**를 선택합니다.
2. 활성 금속과 담체를 지정합니다. 필요하면 조촉매와 담체를 추가하고,
   전체 질량 비율이 맞는지 확인합니다. 라이브러리 재료를 고르면 저장된
   단가와 출처가 연결됩니다. 직접 입력한 가격은 직접 입력값으로 표시됩니다.
3. **제조법**에서 제조 경로 카드를 선택합니다. 카드의 가공비는 재료비를
   제외한 값입니다. 생산 규모를 바꾸면 해당 규모에 맞는 장비로 제조
   단계가 바뀝니다. 동일한 장비를 여러 번 쓰는 경로는 반복 횟수도 반영합니다.
4. 필요하면 폐촉매 **회수 가치**를 포함하고 계산을 실행합니다.
5. 결과의 납품 기준 촉매 단가, 재료비·가공비·간접비·판매 마진을 확인합니다.
   **출처 근거**에서 각 재료의 가격 기준 시점과 원자료 링크를 볼 수 있습니다.

**일부 미산정** 표시는 단가 자료가 없는 제조 단계가 있다는 뜻입니다.
오토클레이브나 동결건조 등 미산정 공정의 비용은 총액에 들어 있지 않습니다.
카드의 표시만 보고 전체 제조 경로가 모두 계산되었다고 해석하지 마세요.

## 전극 조립체 계산

**전기촉매**를 선택한 뒤 연료전지, 수전해 또는 직접 메탄올 연료전지처럼
응용 분야를 고릅니다. 촉매 분말, 아이오노머, 멤브레인, 기재와 제조 경로를
확인하고, 유효 면적·촉매 담지량·아이오노머/촉매 비율을 입력합니다.

주요 결과는 **유효 면적 cm²당 전극 조립체 원가**입니다. 재료별 내역과
원가 비중도 같은 면적 기준입니다. 별도로 표시되는 촉매 분말의 질량 기준
추정치는 전극 조립체 총액과 구분해서 읽습니다. 제조 시나리오를 적용하면
해당 면적의 장비·인건비·시설 비용이 추가됩니다.

기본 재료는 응용 분야와 제조 경로에 따라 정해집니다. 구체적인 선택 순서와
현재 규칙의 한계는 [전극 재료 기본값 표](audit/electrode-defaults-2026-09-06.md)에
정리되어 있습니다.

## 가격 기준과 출처 확인

**가격 기준**은 앱 전체의 계산과 벤치마크 비교에 적용됩니다.

- **실무 기준**: 실시간 시세를 우선 사용합니다. 저장된 시세가 없으면
  지수 보정 가격이나 기준 가격이 적용될 수 있으므로 출처를 확인합니다.
- **학술 기준**: IMF PCPS와 Johnson Matthey의 저장된 월평균을 사용합니다.
  월평균은 최근 발표 월인지로 판단하며, 실시간 시세의 날짜 규칙을 적용하지
  않습니다. 월별 시계열이 없는 금속은 출처가 표시된 기준 가격을 유지합니다.

담체는 학술 기준에서 UN Comtrade 수입 단가 시계열에 연결될 수 있습니다.
자료가 없으면 라이브러리 가격을 유지합니다. 수입 단가는 여러 등급이 섞인
시장 수준의 지표이므로 촉매용 고순도 제품 견적과 같지 않습니다.

## 비교와 추정 범위

**문헌 벤치마크**에서는 같은 반응군의 촉매 후보를 비교하고 계산기로
불러올 수 있습니다. 경제성·출처 근거·제조 경로·성능의 가중치를 바꾸면
순위도 달라질 수 있습니다. 후보의 문헌 요약과 가격 기준을 함께 확인합니다.

**추정 범위**에서는 현재 조성에 가격·생산 규모의 변동 폭을 적용해
몬테카를로 계산을 실행합니다. 같은 조건이라도 시드를 지정하지 않은 실행은
조금씩 다른 표본을 사용합니다. API에서는 `seed`를 지정해 결과를 재현할 수
있으며, 논문 재현 명령은 [방법론](methodology.md)에 정리되어 있습니다.

환경 영향 결과의 **반영률**은 전과정평가 계수가 연결된 질량 비율입니다.
탄소·실리카·제올라이트처럼 계수가 없는 재료는 자료 공백으로 남습니다.
낮은 반영률을 낮은 환경 영향으로 해석하지 않습니다.
